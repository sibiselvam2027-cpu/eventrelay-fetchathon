# EventRelay Coordinator

EventRelay coordinates event-day issues: clarify, offer, obtain crew acceptance, follow up, escalate, and require reporter-confirmed resolution in ASI:One.

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Hosted on Agentverse with direct uAgents and ACP. ASI:One is the user interface. Bundled people and physical work are explicitly simulated.

Coordinator prompts: 'There is a water issue in the dining hall'; 'Drinking water has run out'; 'Show status'; 'The problem is still not resolved'. Native cards guide clarification and confirmation.
